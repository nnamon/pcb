# Review 8: milestone M1 (project file and explicit edits)

Independent reviewer, 4 Nov 2026, at commit cd56b9f. Saved by the designer from the reviewer's hand-back. The reviewer's scripts joined the suite in `tests/review8/`.

**Found sound:**
- The full suite passed (31 of 31 steps, 645 s), and every JSON output from about 45 probe runs matched its schema with the right exit code.
- Edit refusals carried the documented codes: wrong net, no target, locked, wrong `from`, the same item twice (also once by uuid and once by position), duplicates without `all`, unknown field, unknown net, bad layer, a point off the board, a free end with the other end still checked.
- On boards without zones, edit results were byte-identical apart from the operations; the input never changed; rejected results went only to `.rejected`.
- `move_footprint` moved pads and graphics exactly as pcbnew does on a rotated, flipped footprint.
- Diff was right on moved, turned, flipped and removed footprints, an added duplicate track, via size and track width changes, and a git revision.
- Status: version-mismatch warned; the tag lookup matched the first TAGS.tsv column exactly; unknown keys and wrong schemas were refused with `data.problems`.
- Route: second-run copper outside the region was dropped; the routable layers applied to both runs; `still_open` came from KiCad DRC; `--width` laid copper at the width asked.
- `verify_edit` reads with kisexp, not pcb's parser.

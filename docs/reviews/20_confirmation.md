# Review 20: confirmation of review 19's closures

Independent reviewer, 5 Nov 2026, worktree at commit 5537cc3, binary built from that tree. Probes in `tests/review20/`, verdicts in `tests/review20/check.py`: 54 verdicts pass, 7 fail (58 twice, 59 three times, 60, 61), 3 notes. Exit 1. Review 19's runner passes 70 of 70 on this binary (`PCB_R19_BASE` set to this review's M4 flow).

All 12 closures hold for what they claim. Four new findings could put a wrong rotation on an ordered board or leave a part off it:
- A part with more than two pads matched by shape, whose pad centres repeat under a half or quarter turn, releases at the wrong turn (58).
- A BOM or position-file flag cleared in the schematic, or set by hand in pcbnew, stays on the board unseen, and the release leaves the part out (59).
- Any schematic field named DNP marks the part not fitted, whatever its value (60).
- The schematic is not a gate input and the release does not compare the board with the circuit, so a schematic changed after the gate releases the old circuit (61).

## Rerunning the probes

```
cd tools/pcb && cargo build --release
PCB_FREEROUTING_JAR=/opt/freerouting/freerouting-2.5.0.jar python3 tests/review20/check.py target/release/pcb /tmp/review20/run
PCB_R20_BASE=<a project the M4 flow has released> python3 tests/review20/check.py target/release/pcb /tmp/review20/run dnp20.py
```

Without `PCB_R20_BASE` the first probe that needs it runs the M4 fixture flow into `_flow` beside the workdir (a few minutes, mostly the route). Probes: `slot20.py` (47 and 51: off-centre slots against pcbnew's drill and copper, the offset solver, check on thin rings), `polarity20.py` (48 and 58: two-pad and symmetric parts matched by shape, through release), `dnp20.py` (49, 59, 60, 61: schematic flags through sync, check, gate and release on the routed M4 board), `resync20.py` (55: part changes on the routed board), `stale20.py` (50: harmless saves and edited paste windows). Shared helpers in `r20lib.py`, which uses `tests/lib` only for the output contract.

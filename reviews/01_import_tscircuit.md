# Review 1: `pcb import-tscircuit` and `tests/verify_import.py`

Independent reviewer, 30 Oct 2026, at commit db6939b. Saved by the designer from the reviewer's hand-back. The closure column is the designer's, at commit 4b288c4. Each closure is tested in `tests/verify_import.py`, `tests/mutations.py` or the unit tests.

**Verdict:** copper (positions, pad sizes, oval slots, nets) on r36a is correct. Two blockers made the imported board wrong as a KiCad model. Several paths silently drop data that r36a happens not to contain, and the check could not see any of these problems.

| # | Severity | Finding | Closure |
| --- | --- | --- | --- |
| B1 | BLOCKER | Courtyard rects ignore `ccw_rotation`, so every 90/270° part's courtyard is turned 90°. KiCad DRC reports 26 overlaps against tscircuit's 7. Other `pcb_courtyard_*` types are skipped. || Fixed: courtyard rects are turned by `ccw_rotation` and written as `fp_poly`; other courtyard kinds bail. Test: courtyard corners against KiCad's `GetCourtyard`; mutation `m_courtyard`. KiCad DRC now reports the same 7 overlaps as tscircuit. |
| B2 | BLOCKER | Bottom footprints get orientation = tscircuit rotation, but KiCad's flipped-footprint convention is rotation + 180. Copper is correct; CPL rotation and a footprint update would turn BT101 180° and swap its + and −. || Fixed: back-side footprints get rotation + 180. Test: BT101 rebuilt from the KEYSTONE_2464 library pads with pcbnew's Flip, 0 mismatches; mutation `m_bt101_turned`. |
| S1 | SHOULD-FIX | No footprint type attribute (`smd`/`through_hole`): `kicad-cli pcb export pos --smd-only` gives 0 rows. DNP BT101 is written as `smd`. || Fixed: `(attr smd|through_hole)`, plus `exclude_from_pos_files exclude_from_bom` for DNP. Test: attributes and DNP checked; mutation `m_attr`. |
| S2 | SHOULD-FIX | Pad nets come only from source_traces pairing a port with a net. A port-to-port trace gives no net, and a port on two nets silently keeps the first. || Fixed: nets from union-find over all source traces; a port joining two named nets is an error. |
| S3 | SHOULD-FIX | Track and via nets depend on the non-standard `net_name` field. Without it they land on net 0 silently. || Fixed: track and via nets are derived from the pads they touch; no net found is an error. |
| S4 | SHOULD-FIX | Route gaps are dropped silently: a layer change between wire points, or a `via` route point. || Fixed: a `via` route point is written as a via; a layer change without one is an error. Unit tests `rejects_layer_change_without_via`, `via_route_point_joins_both_sides`. |
| S5 | SHOULD-FIX | A polygon pad anchored at its bounding-box centre can sit outside a non-convex polygon (stray copper dot, wrong attach point). || Fixed: the anchor is placed inside the polygon (`point_in_poly`). Unit test `polygon_inside`. |
| S6 | SHOULD-FIX | Unknown elements (`pcb_cutout`, others), `hole_offset_*`, corner radii and pill radius are dropped silently. || Fixed: element allow-list, unknown elements bail; hole offsets bail; roundrect and pill radius handled. Unit test `rejects_unknown_elements`. |
| S7 | SHOULD-FIX | A pad can get an empty number. || Fixed: a pad number is never empty. |
| S8 | SHOULD-FIX | The test misses pad layer side, number, pinfunction, outline, courtyards, attributes, LCSC/DNP, via span, slot axis and polygon shape. A mutated board with all of these changed passed. || Fixed: `verify_import.py` checks every listed property; `mutations.py` shows 9 of 9 mutations caught and the unmutated board passing. |
| N1 | NOTE | No design rules imported; KiCad defaults to 0.2 mm clearance. || Fixed: `import-tscircuit` writes a `.kicad_pro` with the JLCPCB rules (0.15 mm clearance). |
| N2 | NOTE | `--layers 4` against `num_layers 2` is not reported; non-through vias are written as through. || Fixed: reported as a warning. Non-through vias still bail. |
| N3 | NOTE | tscircuit paste and mask settings dropped (intended for paste). || Accepted: paste is regenerated by KiCad; mask settings are not used on this board. |
| N4 | NOTE | The transform assumes the board centre is (0, 0). || Fixed: the transform uses the board centre. |
| N5 | NOTE | An outline that repeats its first point writes a zero-length Edge.Cuts line. || Fixed: the closing outline point is dropped. |
| N6 | NOTE | Library ids containing ':' are rewritten by KiCad. || Fixed: library ids are sanitized. |
| N7 | NOTE | `value_of` writes 0 Ω as "0pΩ". || Fixed: values are ASCII ("0R", "20.5k", "100nF"). Unit test `values`. |
| N8 | NOTE | The unit test `local_undoes_rotation` only tests a round trip, not KiCad's angle convention. || Fixed: unit test `kicad_angle_convention` checks the convention. |
| N9 | NOTE | `board.rs` reads a `gr_poly` outline without its closing segment; `gr_arc` becomes two chords; `gr_circle` is ignored. || Fixed: closed `gr_poly`, three-point arcs and `gr_circle` read. Unit tests in `board.rs`. |
| N10 | NOTE | The board-hole naming check is specific to this board's source. || Accepted: the H1–H8 naming check stays specific to this board; it is a board test, not part of `pcb`. |
